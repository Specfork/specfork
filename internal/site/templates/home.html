Fork an app spec. Let your agent build it.

Specfork is a library of stack-free app specs: numbered, testable requirements with an acceptance check for each. Pick one, change what you need, and hand the bundle to Claude Code or any coding agent. Everything a spec builds on, like sign-in or teams, comes along automatically.
